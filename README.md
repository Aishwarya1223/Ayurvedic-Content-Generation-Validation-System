# Ayurvedic Content Generation & Validation System

*A Multi-Agent Pipeline for Brand-Safe Content Creation Using RAG, Fact-Checking, and Tone Editing*

## 🚀 Overview
This project implements an end-to-end **Agentic AI content generation system** designed specifically for **Kerala Ayurveda–style content**.  
It produces **safe, accurate, and brand-aligned** articles using:

- Outline generation  
- Writer agent  
- RAG fact-checker  
- Tone editor  

## 🧠 Features
- OutlineAgent  
- WriterAgent  
- FactCheckerAgent  
- ToneEditor  
- Evaluation metrics  

## 🏗 Architecture
```
Brief → OutlineAgent → WriterAgent → FactCheckerAgent → ToneEditor → Final Output
```

## 📝 How to Run
```
pip install -r requirements.txt
python main.py
```
